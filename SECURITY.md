# Security

Hurtly has no server or accounts, and keeps entries on the user's device. Security issues still matter: for example, anything that could leak entries or a stored API key, or run untrusted code in the app.

## Reporting a vulnerability

Please **don't open a public issue.** Report it privately through GitHub: on the repository's **Security** tab, choose **Report a vulnerability**.

Include what you found, how to reproduce it, and what it could expose. You'll get a reply as soon as the maintainer can; this is a hobby project, so please allow a few days.

## Supported versions

Only the latest version on `main`, which is what the live site runs.
